# Orakel

Ein Schätz- und Bluffspiel fürs Handy, für mindestens 3 Leute.

Alle bekommen dieselbe Schätzfrage, nur einer nicht: das Orakel. Es kennt nur die Einheit und muss bluffen. Reihum sagt jeder seine Schätzung, danach wird abgestimmt, wer das Orakel ist.

- Jeder spielt auf seinem eigenen Handy
- Kein Server nötig: Gleicher Raum-Code und gleiche Spielerzahl ergeben auf allen Handys dieselbe Frage und dasselbe Orakel
- 141 Schätzfragen in 8 Themen in `fragen.js`, dort lassen sich auch neue Fragen hinzufügen
- Karte nur sichtbar, solange man sie gedrückt hält
- Diskussions-Timer mit „3, 2, 1, zeigt aufs Orakel!“
- Letzte Chance: Das enttarnte Orakel darf die Frage raten, bevor sie gezeigt wird
- Einstellungen: Themen wählen, Themen-Hinweis fürs Orakel, zwei Orakel ab 7 Spielern

Gebaut mit HTML, CSS und JavaScript, zusammen mit Claude.
